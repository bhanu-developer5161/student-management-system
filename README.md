# 🎓 Student Management System

**A modern Student Management System frontend built with React.js**

---

## 📌 About

**Student Management System** is a responsive frontend application built with **React.js** to manage students, student profiles, attendance, academic performance, courses, departments, and reports from a centralized admin dashboard.

This project was developed through a **10-day daily development challenge**, with new features and improvements implemented throughout the development process.

# 🚀 Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/bhanu-developer5161/student-management-system.git
```

## 2. Navigate to the Project

```bash
cd student-management-system
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Start Development Server

```bash
npm run dev
```

## 5. Create Production Build

```bash
npm run build
```

# 💾 Data Storage

This project currently uses **Browser LocalStorage** for data persistence.

The application stores and manages:

* Student information
* Attendance
* Marks
* Courses
* Departments

No external backend database is required for the current frontend version.
