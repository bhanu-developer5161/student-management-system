# 🎓 Student Management System

A modern **Student Management System frontend** built using React.js and Bootstrap.

This project allows administrators to manage student information, view student profiles, track attendance, and monitor academic performance.

---

## 🚀 Features

### Dashboard
- Total Students
- Total Courses
- Departments
- Welcome section
- Quick navigation

### Student Management
- Add Student
- View Students
- Search Students
- Edit Student
- Delete Student
- Student ID validation
- Form validation
- LocalStorage data persistence

### Student Profile
- Personal Information
- Contact Information
- Academic Information
- Course and Department
- Attendance percentage
- Attendance progress bar
- Subject-wise marks
- Automatic grade calculation
- Average marks calculation
- Performance status
- Print Student Profile
