# 🎓 Student Management System

A modern and responsive **Student Management System frontend** built using **React.js, JavaScript, Bootstrap, HTML5, and CSS3**.

This project is designed to provide an admin dashboard for managing students, tracking attendance, viewing student profiles, and monitoring academic performance.

---

## 🚀 Project Overview

The Student Management System helps administrators manage student-related information from a single dashboard.

The current version is a **frontend-only application**. Student data is stored using the browser's **LocalStorage**, so no backend or database is required.

---

## ✨ Features

### 📊 Dashboard

- Admin dashboard
- Total Students
- Total Courses
- Total Departments
- Welcome section
- Quick navigation
- Responsive dashboard cards

### 👨‍🎓 Student Management

- Add new students
- View student list
- Search students
- Edit student information
- Delete students
- Student ID management
- Form validation
- Student profile page
- LocalStorage data persistence

### 👤 Student Profile

Each student has a detailed profile containing:

- Student ID
- Full Name
- Gender
- Date of Birth
- Email
- Phone
- Address
- Course
- Department
- Attendance
- Subject-wise marks
- Average marks
- Automatic grades
- Performance status
- Print profile option

### 📋 Attendance Management

The Attendance module provides:

- Total working days
- Present days
- Absent days
- Attendance percentage
- Attendance progress bar
- Attendance search
- Automatic attendance calculation
- Good attendance status
- Warning status
- Low attendance status
- LocalStorage persistence
